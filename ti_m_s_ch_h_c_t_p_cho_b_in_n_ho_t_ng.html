Hướng Dẫn Triển Khai & Phát Triển

Dành cho chủ website

1. Cách đưa lên GitHub Pages

  1. Tạo một Repository mới trên GitHub (ví dụ: be-vui-hoc).
  2. Lưu mã nguồn này thành file tên index.html.
  3. Upload file index.html lên repository đó.
  4. Vào tab Settings -> Pages -> mục Build and deployment chọn Branch là main (hoặc master) và thư mục / (root) rồi Save.
  5. Sau vài phút, GitHub sẽ cung cấp link website trực tuyến của bạn!

2. Cách thêm chủ đề hoặc sản phẩm mới

Mở file index.html và tìm mảng dữ liệu productsData trong thẻ script bên dưới. Bạn có thể thêm sản phẩm mới theo cấu trúc:

{
  id: 19,
  title: "Chủ đề mới của bé",
  category: "logic",
  desc: "Mô tả ngắn gọn về lợi ích chủ đề...",
  image: "link_anh_hoặc_placeholder",
  basePrice: 19000 // Tương ứng giá cơ bản cho 10 trang
}

Giá tiền sản phẩm tự động tính theo công thức thứ tự (sản phẩm 1 = 1,000đ nhân hệ số trang, v.v.) hoặc tùy chỉnh trực tiếp trường basePrice.
